Scalar Product Transform: Symmetry Scores from Arbitrary Patch Embeddings
=========================================================================

The Scalar Product Transform (SPT) computes scores for C_2 rotational
symmetries, also known as point reflection symmetries, from patch embeddings
as, e.g., computed by Franca or DINO. High scores correspond to symmetry
centers, and, for each potential symmetry center point, the symmetry region is
estimated.

This code implements the algorithm described in:

> C. Dalitz, J. Beeker: "Symmetry Detection with Patch Embedding Models
> by Means of a Scalar Product Transform."
> accepted for The International Conference on Computer Vision Theory
> and Applications (VISAPP) (2027)
> https://doi.org/10.48550/arXiv.2611.21363

The method will be presented at VISAPP in Februray 2027, and the code
will be uploaded here before the presentation.
